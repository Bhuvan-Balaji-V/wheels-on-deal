# Home Page Images

Add your home page hero background and other homepage images here.

## Hero Section Background:
- `hero-bg.jpg` - Main hero background image (1920x1080 recommended, landscape)
  - This is the full-screen background image on the home page
  - Should be high-quality and eye-catching
  - Recommended: Mahindra Thar or luxury car image

## Image Guidelines:
- Format: JPG, PNG, or WebP
- Resolution: 1920x1080 or higher for hero background
- Optimize for web (compress to reduce file size)
- Use professional, high-quality images
- Landscape orientation preferred

Once you add the images here, they will automatically appear on your website.
